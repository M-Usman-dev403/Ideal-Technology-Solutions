# Ideal Technology Solutions — Phase 1 Homepage

- `index.html` — self-contained build. Upload to GitHub and enable Pages; no build step, no dependencies.
- `assets/` — original media (logo, partner logos, trimmed transparent PNGs used by the partner cards, particles.js).
- `source/` — editable source: the design component plus its runtime (`support.js`). Open the `.dc.html` next to `support.js` to edit.

The Google Maps embed loads from Google, so the map only appears when the page is served online.
